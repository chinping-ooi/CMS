Build a Customer Management System (CRM) using:

**Technology Stack**

* Backend: ASP.NET Core MVC / .NET
* Frontend: Bootstrap + jQuery
* Database: Postgresql
* Use Entity Framework Core for database access

## Features

### 1. Customer Management

* Customer list page
* Customer profile management
* Store customer information:

  * Company name
  * Contact person
  * Phone
  * Email
  * Customer status
* Search and filter customers
* View customer history

### 2. Revenue Management

* Track customers that generate revenue
* Record revenue amount by customer
* Show customer revenue ranking
* Display revenue summary

### 3. Customer To-Do List

* Create follow-up tasks linked to customers
* Task fields:

  * Task title
  * Customer
  * Assigned user
  * Due date
  * Status
  * Notes
* Task status:

  * Pending
  * In Progress
  * Completed
* Show pending and overdue tasks

### 4. Purchase Management

* Record customer purchases
* Store:

  * Product/service name
  * Purchase date
  * Quantity
  * Amount
* Show customer purchase history
* Show top purchasing customers

### 5. Dashboard

Create a dashboard with:

* Total customers
* Active customers
* Total revenue
* Top revenue customers
* Total purchase amount
* Pending tasks
* Overdue tasks

Dashboard should include charts and summary cards.

## Development Requirements

* Use Bootstrap for UI design
* Use jQuery and AJAX for dynamic page updates
* Use ASP.NET Core MVC architecture
* Use Entity Framework Core with Postgresql
* Create clean database tables and relationships:

  * Customers
  * Revenue
  * Purchases
  * Tasks
  * Users
* Implement CRUD operations
* Include search, filter, pagination
* Create responsive and user-friendly pages
